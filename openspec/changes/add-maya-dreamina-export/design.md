## Design

Combine installation and two export modes in one skill because the official uploader owns all three actions. Use the supplied manual for the macOS/Windows installer names and Maya Plug-in Manager path, then verify the actual installed UI. The existing-video path does not require Maya scene rendering. Distinguish local artifact, uploader link, web reference, and generated result. Keep the skill independent of unavailable `maya_runner.py` scripts and of vendor implementation details.
